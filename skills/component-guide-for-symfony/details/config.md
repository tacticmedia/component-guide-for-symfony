# Config (`symfony/config`): details

**Applies to:** Symfony 8.1

## Key features and concepts

- **Configuration tree:** A class that implements `ConfigurationInterface` returns a `TreeBuilder`, and the tree defines the keys, types, defaults and rules. Do not read container parameters, env vars or the machine state in the tree. Symfony generates the configuration reference from the tree, so the tree must be the same in each environment. If a default value depends on such data, resolve it in the extension. Entry point: `ConfigurationInterface::getConfigTreeBuilder()`, `new TreeBuilder('acme_social')`, `TreeBuilder::getRootNode()`.
- **Node types:** `scalarNode()`, `stringNode()`, `booleanNode()`, `integerNode()`, `floatNode()`, `enumNode()`, `arrayNode()` and `variableNode()` create nodes that check the type of the value. `min()` and `max()` limit a number. `values()` or `enumFqcn()` set the allowed values of an enum node. With `enumFqcn()` and a backed enum, the node converts a string or an integer to the enum case. Entry point: `NodeBuilder`, `NumericNodeDefinition::min()`, `EnumNodeDefinition::enumFqcn()`.
- **Lists and maps:** A prototype (`arrayPrototype()`, `scalarPrototype()`, `stringPrototype()` and others) defines an entry that can repeat. A list from a later file appends its entries, and a map merges the entries that have the same key. `useAttributeAsKey('name')` turns list entries into map entries with their `name` value as the key. Then each list entry must have that key. The second argument of `arrayNode('connections', 'connection')` sets the singular name. Entry point: `ArrayNodeDefinition::arrayPrototype()`, `ArrayNodeDefinition::useAttributeAsKey()`, `NodeBuilder::arrayNode()`.
- **Defaults and required values:** `defaultValue()`, `defaultTrue()`, `defaultFalse()`, `defaultNull()`, `isRequired()`, `cannotBeEmpty()`, `addDefaultsIfNotSet()` and `requiresAtLeastOneElement()` control missing and empty values. A node cannot be required and have a default value: the definition throws an `InvalidDefinitionException`. Entry point: `NodeDefinition::defaultValue()`, `NodeDefinition::isRequired()`, `ArrayNodeDefinition::addDefaultsIfNotSet()`.
- **Normalization:** Before validation, an array node changes dashes in keys to underscores (unless `normalizeKeys(false)`). Then the node runs the `beforeNormalization()` closures and applies the `treatNullLike()`, `treatTrueLike()` and `treatFalseLike()` values. `castToArray()` and `acceptAndWrap(['string'])` turn a scalar into an array. Pass an array to `acceptAndWrap()`, because a string argument throws a `TypeError`. Entry point: `NodeDefinition::beforeNormalization()`, `ExprBuilder::castToArray()`, `ArrayNodeDefinition::acceptAndWrap()`.
- **Validation rules and unknown keys:** `validate()` adds a rule for the final value, for example `->validate()->ifNotInArray(['mysql', 'sqlite'])->thenInvalid('Invalid driver %s')`. A `then()` closure can return a new value. If a rule closure throws an exception that is not a Config exception, the node wraps it in an `InvalidConfigurationException` with the node path. An unknown key causes an "Unrecognized option" error, unless the node calls `ignoreExtraKeys()`. The message adds a "Did you mean" hint for a similar key. Otherwise, it lists the available options. Entry point: `NodeDefinition::validate()`, `ExprBuilder`, `ArrayNodeDefinition::ignoreExtraKeys()`.
- **Merging of several files:** `Processor::processConfiguration()` normalizes each array, merges the arrays in their order, then finalizes and validates the result. If you process parsed files yourself, remove the root key from each array first. A later scalar value replaces an earlier one, arrays merge key by key, and a prototyped list without `useAttributeAsKey()` appends the entries. `performNoDeepMerging()`, `cannotBeOverwritten()` and `disallowNewKeysInSubsequentConfigs()` change this behavior. Entry point: `Processor::processConfiguration()`, `ArrayNodeDefinition::performNoDeepMerging()`, `NodeDefinition::cannotBeOverwritten()`.
- **Optional sections:** `canBeEnabled()` and `canBeDisabled()` add an `enabled` key with the default `false` or `true`. For a `canBeEnabled()` section, the values `true`, `null` or an array without `enabled: false` enable the section. In the extension, `isConfigEnabled($container, $config['section'])` reads the flag and resolves parameters in it. Entry point: `ArrayNodeDefinition::canBeEnabled()`, `Extension::isConfigEnabled()`.
- **Deprecation and documentation:** `setDeprecated('acme/package', '1.2')` triggers a deprecation when a configuration sets the option. `info()` and `example()` add comments to the reference dump. `docUrl($uri, $package)` replaces `{package}`, `{version:major}` and `{version:minor}` with the name and the installed version of `$package` when you call it. If you omit `$package`, the placeholders become empty strings. The `debug:config` and `config:dump-reference` commands show the `docUrl()` of the root node. Entry point: `NodeDefinition::setDeprecated()`, `NodeDefinition::info()`, `NodeDefinition::docUrl()`.
- **Bundle configuration with `AbstractBundle`:** In the bundle class, `configure(DefinitionConfigurator $definition)` defines the tree with `$definition->rootNode()`. `loadExtension(array $config, ContainerConfigurator $container, ContainerBuilder $builder)` gets the merged and validated array. `$definition->import('../config/definition.php')` loads parts of the tree from PHP files that return a closure. The root key is the snake case of the bundle name without `Bundle`. Entry point: `Symfony\Component\HttpKernel\Bundle\AbstractBundle`, `DefinitionConfigurator`.
- **Extension classes:** In `load()`, an extension that extends `Extension` calls `$this->processConfiguration(new Configuration(), $configs)`. If a `Configuration` class in the namespace of the extension has no required constructor arguments, `getConfiguration()` returns it. `ConfigurableExtension` calls `loadInternal()` with the merged array. Entry point: `Extension::processConfiguration()`, `Extension::getConfiguration()`, `ConfigurableExtension::loadInternal()`, `AbstractExtension`.
- **Env var placeholders:** At compile time, a `%env(NAME)%` value is a placeholder string. Scalar, string, boolean, integer, float and variable nodes accept it, and the typed nodes check the type of the env var. For a boolean, integer or float node, use an env var processor, for example `%env(bool:NAME)%`. An array node rejects it with an `InvalidTypeException`. Do not inspect the value in `beforeNormalization()`, `validate()` or `loadExtension()`. Pass it to a service argument or a parameter. Entry point: `%env(NAME)%` in a configuration value.
- **File locator and loaders:** `FileLocator::locate($name, $currentPath, $first)` searches the current path first, then the configured directories, and returns the first match or all matches. `LoaderResolver` selects the first loader whose `supports()` returns `true`, and `DelegatingLoader` calls that loader. `FileLoader::import()` accepts glob patterns, `$ignoreErrors` and `$exclude`, and detects circular imports. `ContainerConfigurator::import()` passes `$exclude`, but an `exclude` key in a YAML or PHP-array `imports` entry has no effect. Declare `load()` with the return type `mixed` or a narrower type, not `void`. Entry point: `FileLocator`, `LoaderResolver`, `DelegatingLoader`, `FileLoader::import()`.
- **Resource-based cache:** `ConfigCache::write($code, $resources)` writes a generated PHP file and a `.meta` file of resources, and `isFresh()` checks them. In debug mode, a changed `FileResource`, `DirectoryResource`, `GlobResource`, `FileExistenceResource` or `ReflectionClassResource` makes the cache stale. Outside debug mode, an existing cache file is always fresh. In debug mode, the `config_cache_factory` service also uses each autoconfigured service that implements `ResourceCheckerInterface`. Entry point: `ConfigCache`, `ConfigCacheFactory::cache()`, `ResourceCheckerInterface`.
- **Reference dumps and array shapes:** `YamlReferenceDumper` and `XmlReferenceDumper` print a tree with its defaults and comments. `ArrayShapeGenerator::generate()` returns the PHPDoc array shape of a tree. In debug mode, FrameworkBundle writes these shapes as `@psalm-type` types to `config/reference.php`, so IDEs and static analysis tools check PHP configuration arrays. In a bundle, do not rely on this file, because it is for applications only. Entry point: `YamlReferenceDumper`, `ArrayShapeGenerator`, `config/reference.php`.

## Entry points

- Configuration tree: `Symfony\Component\Config\Definition\ConfigurationInterface`, `Symfony\Component\Config\Definition\Builder\TreeBuilder`, `Symfony\Component\Config\Definition\Builder\NodeBuilder`, `Symfony\Component\Config\Definition\Builder\ArrayNodeDefinition`, `Symfony\Component\Config\Definition\Builder\ExprBuilder`.
- Processing: `Symfony\Component\Config\Definition\Processor` (`processConfiguration()`, `process()`).
- Without FrameworkBundle: parse each file yourself, for example with `Yaml::parse()`, and remove the root key from each array. Then merge the arrays with `Processor::processConfiguration()` and your `ConfigurationInterface` class. `FileLocator`, `LoaderResolver`, `DelegatingLoader` and `ConfigCache` need no container.
- Bundle hooks: `Symfony\Component\HttpKernel\Bundle\AbstractBundle` (`configure()`, `loadExtension()`, `prependExtension()`); `Symfony\Component\DependencyInjection\Kernel\AbstractBundle` for applications without HttpKernel (8.1); `Symfony\Component\Config\Definition\Configurator\DefinitionConfigurator` (`rootNode()`, `import()`).
- Extensions: `Symfony\Component\DependencyInjection\Extension\Extension` (`processConfiguration()`, `getConfiguration()`, `isConfigEnabled()`), `Symfony\Component\DependencyInjection\Extension\AbstractExtension`, `Symfony\Component\HttpKernel\DependencyInjection\ConfigurableExtension`.
- Loaders: `Symfony\Component\Config\FileLocator`, `Symfony\Component\Config\Loader\LoaderInterface`, `Symfony\Component\Config\Loader\Loader`, `Symfony\Component\Config\Loader\FileLoader`, `Symfony\Component\Config\Loader\LoaderResolver`, `Symfony\Component\Config\Loader\DelegatingLoader`, `Symfony\Component\Config\Loader\GlobFileLoader`.
- Cache and resources: `Symfony\Component\Config\ConfigCache`, `Symfony\Component\Config\ConfigCacheFactory`, `Symfony\Component\Config\ResourceCheckerConfigCacheFactory`, `Symfony\Component\Config\ResourceCheckerInterface`, `Symfony\Component\Config\Resource\FileResource`, `DirectoryResource`, `FileExistenceResource`, `GlobResource`, `ClassExistenceResource`, `ReflectionClassResource`, `ComposerResource`.
- Services in an application: `file_locator` (autowire `Symfony\Component\DependencyInjection\Kernel\FileLocator`; it also resolves `@AcmeBundle/...` paths), `config_cache_factory` (no autowiring alias; use `#[Autowire(service: 'config_cache_factory')]`). Service tag: `config_cache.resource_checker` (autoconfigured for `ResourceCheckerInterface`).
- Console commands (FrameworkBundle): `debug:config [name] [path] [--resolve-env] [--format=txt|yaml|json]` shows the current, merged configuration; `config:dump-reference [name] [path] [--format=yaml|xml]` shows the default configuration and its comments (`path` only with `yaml`).
- Dumpers and shapes: `Symfony\Component\Config\Definition\Dumper\YamlReferenceDumper`, `Symfony\Component\Config\Definition\Dumper\XmlReferenceDumper`, `Symfony\Component\Config\Definition\ArrayShapeGenerator`; the generated file `config/reference.php`.
- Exceptions: `Symfony\Component\Config\Definition\Exception\InvalidConfigurationException`, `InvalidTypeException`, `InvalidDefinitionException`, `ForbiddenOverwriteException`; `Symfony\Component\Config\Exception\FileLocatorFileNotFoundException`, `LoaderLoadException`, `FileLoaderImportCircularReferenceException`.

## Symbiotic packages

- [DependencyInjection](../packages/dependency-injection.md): Container extensions process the bundle configuration with Config, and the DependencyInjection file loaders extend the Config `FileLoader`; Config validates bundle options, DependencyInjection defines services.
- [HttpKernel](../packages/http-kernel.md): A bundle extends the HttpKernel `AbstractBundle`, and its `configure()` and `loadExtension()` hooks receive a Config `DefinitionConfigurator` and the processed array.
- [FrameworkBundle](../packages/framework-bundle.md): FrameworkBundle gives the `debug:config` and `config:dump-reference` commands, and in debug mode it writes `config/reference.php` from the configuration trees.
- [Routing](../packages/routing.md): Route loaders implement the Config `LoaderInterface`, and the router caches its compiled matcher and generator with a Config cache factory.
- [Translation](../packages/translation.md): The translator caches each compiled message catalogue with a Config cache factory.
- [Yaml](../packages/yaml.md): `config:dump-reference` needs Yaml for its default `yaml` format, and the docs parse YAML files with `Yaml::parse()` before `Processor` merges them.
- [Filesystem](../packages/filesystem.md): Config requires Filesystem, and `ConfigCache::write()` writes the cache file and the `.meta` file atomically with `Filesystem::dumpFile()`.
- [Finder](../packages/finder.md): `GlobResource` needs Finder for extended glob patterns such as `/**/`, and it throws a `LogicException` when Finder is missing.
- [OptionsResolver](../packages/options-resolver.md): OptionsResolver handles the `$options` array of one class at runtime; Config handles nested configuration trees that merge several files.
- [Cache](../packages/cache.md): `ConfigCache` only keeps a generated code file fresh against its source files; use the Cache component to cache application data.

## Changed in 8.0/8.1

- Fluent config builders, for example `return static function (FrameworkConfig $framework) { $framework->workflows()...; };` -> a file in the namespace `Symfony\Component\DependencyInjection\Loader\Configurator` that returns `App::config(['framework' => [...]])`, or a plain array. Version 8.0 removed the fluent format, and FrameworkBundle no longer generates the `Symfony\Config\*Config` classes. Do not return `new AcmeConfig([...])` as UPGRADE-8.0.md shows, because the class does not exist. Some docs pages still show the old format.
- `$this` or the internal scope of the loader in a PHP configuration file -> the `$loader` variable or the `ContainerConfigurator` argument (removed in 8.0).
- XML configuration files -> YAML or PHP files (removed in 8.0).
- `->isRequired()` together with `->defaultValue()` on one node -> use only one of them. Version 8.0 throws an `InvalidDefinitionException`.
- `->fixXmlConfig('connection')` plus `->arrayNode('connections')` -> `->arrayNode('connections', 'connection')` (added in 7.4; a declared argument of the method since 8.0).
- `Symfony\Component\HttpKernel\DependencyInjection\Extension` -> `Symfony\Component\DependencyInjection\Extension\Extension` (deprecated in 8.1).
- `Symfony\Component\HttpKernel\Config\FileLocator` -> `Symfony\Component\DependencyInjection\Kernel\FileLocator` (deprecated in 8.1). In 8.1, the `file_locator` and `config_cache_factory` services come from the DependencyInjection `ServicesBundle`.
- A bundle for an application without HttpKernel -> `Symfony\Component\DependencyInjection\Kernel\AbstractBundle`, with the same `configure()` and `loadExtension()` hooks (new in 8.1).
